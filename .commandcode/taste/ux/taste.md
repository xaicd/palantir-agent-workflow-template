# UX & UI preferences

- Benchmarks established production products for UI/UX and expects the implementation to match them (e.g. NetEase 163 Classroom for course pages, Douyin for feeds/live). Confidence: 0.8
- List/card UI should be information-rich (cover image, description, tags, price/status) and include an explicit primary CTA (e.g. 报名 button on course cards). Confidence: 0.75
- Wants design conventions applied consistently across PC and APP surfaces — e.g. category labels placed in the text area, not overlaid on the image's top-left corner. Confidence: 0.7
- Rejects redundant/duplicated UI: if a new element repeats existing functionality (e.g. a vertical nav duplicating the horizontal nav), remove it rather than keep both — and doesn't want extra nav/entry elements added on a whim ("也别乱加啊，和横导航重复了去掉"). Confidence: 0.7
